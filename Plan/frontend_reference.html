10 · Android Usage access

9:41● LTE ▰

See screen time by app

Optional · Android only

Your Dream Force data keeps working either way.Usage access is a separate Android setting. You can change it at any time.

What this lets Dream Force do

Read Android’s daily usage summaries so you can review time by app on this device, including Dream Force when Android provides a usage record for it.

App names and durations stay on this phone by default. An optional analytics setting may contribute anonymous daily totals for aggregate reports; support never sees your app list.

Turn it on in Settings

Usage accessDream Force · Not enabled

Android Settings opens next. Select Dream Force and enable “Permit usage access,” then return here. You can choose Not now.
